# Royale Rangues Hotel

A multi-page hotel booking website built with HTML, CSS, JavaScript, and PHP.

## Pages

| File | Description |
|---|---|
| `Royale_Rangues.html` | Home — image slideshow, vision, highlights |
| `destination_and_hotel.html` | Browse destinations (Delhi, Mumbai, Bangalore, Kolkata, Chennai) and hotels |
| `offers.html` | Current deals and promotions |
| `membership.html` | Membership tiers and benefits |
| `book.html` | Room booking form |
| `contact.html` | Contact form and info |
| `privacy_policy.html` | Privacy policy |
| `terms_conditions.html` | Terms and conditions |
| `thankyou.html` | Booking confirmation page |

## Tech Stack

- HTML5, CSS3, JavaScript
- PHP (booking form handler)

## Features

- Image slideshow on the homepage
- Multi-city destination explorer with hotel listings
- Membership system
- Booking form with PHP backend
- Fully responsive layout

## Run

No build step needed. Open `Royale_Rangues.html` in a browser for static pages.

For the booking form (`booking.php`) to work, deploy to a PHP-enabled server (e.g. XAMPP, WAMP, or any hosting with PHP support).
